## About this project

A single-page Angular application that shows modern Angular practices:

- **Standalone components** with the new control flow (`@if`, `@for`)
- **Signals** (`signal`, `computed`, `input`, `effect`) for all state
- **Zoneless change detection** and `OnPush` everywhere
- Light/dark theme with saved preference, a responsive layout and accessible navigation
- All CV content lives in one typed data file: [`src/app/data/cv.data.ts`](src/app/data/cv.data.ts)
- Automatic deployment to **GitHub Pages** with GitHub Actions on every push to `main`

### Run locally

```bash
npm install
npm start          # http://localhost:4200
npm run build      # production build in dist/portfolio/browser
```
